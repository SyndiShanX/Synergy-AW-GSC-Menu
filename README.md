# Synergy AW GSC Menu

An Exo-Zombies GSC Mod Menu that uses [S1x/Alterware](https://alterware.dev/)

This Menu is a Work-In-Progress, so expect changes and possibly some Bugs

If you use any Code from my Menu, your Menu also has to be Open-Source as per the [GNU GPLv3 License](https://github.com/SyndiShanX/Synergy-AW-GSC-Menu/blob/main/LICENSE.md)

If you have any Issues/Suggestions, please Submit them in [Issues](https://github.com/SyndiShanX/Synergy-AW-GSC-Menu/issues)

### Requirements: [S1x/Alterware](https://alterware.dev/)

## Installation:

* Download [Synergy.gsc](https://syndishanx.github.io/Synergy-AW-GSC-Menu/Synergy.gsc)

* Place it into `data\scripts` in the Game Folder

* Download [s1-mod.exe](https://syndishanx.github.io/Synergy-AW-GSC-Menu/s1-mod.exe)

* Place it into your Game Folder, replacing the default Client, this is a fixed version by lusif3ar
